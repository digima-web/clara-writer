F4Chiedi a Claude  (Maiusc + F4: nuova conversazione)

F7Nuovo articolo, libro o capitolo, o importa file Word
F8Annulla le modifiche di Claude
F9  /  F10Cambia carattere  /  cambia colori (Maiusc + F10: lingua)
