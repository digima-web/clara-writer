**Clara Writer 1.0.0**: the first public version.

### Install
Download **Install-Clara-Writer.bat** below and double-click it. It downloads Clara Writer, creates a desktop icon and, the first time, installs everything it needs (Git, Python, Pandoc, Claude Code). You need a Claude subscription (Pro or higher).

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

### What's inside
- Large-print editor with three high-contrast themes and the Atkinson Hyperlegible Next typeface
- Claude built in: corrections, advice, research, organising articles and books; every change is highlighted and can be undone with F8
- Read-aloud (F3) and dictation (F5)
- One-key export to Word (F12)
- English and Italian (Shift + F10 to switch)
- Automatic updates
