**Clara Writer 1.1.0**

### New
- **Big cursor:** a thick, coloured, blinking cursor that is easy to find on the page.
- **Key bar:** the main keys are always shown at the bottom of the screen (Shift + F2 hides it).
- **Quick requests to Claude:** Ctrl + 1 spelling, Ctrl + 2 grammar and punctuation, Ctrl + 3 repetitions and long sentences, Ctrl + 4 title ideas.
- **Read the paragraph:** Shift + F3 reads aloud the paragraph you are in.
- **Find:** Ctrl + F to find a word, Ctrl + G for the next one; the line is read aloud.
- **Import Word files:** put .docx, .odt, .rtf or .txt files in the Import folder, then F7 > Import Word files.

Changed: the reading speed is now Ctrl + Shift + F3.

If you already have Clara Writer, it updates itself the next time you start it.

**Clara Writer 1.1.0**

### Novità
- **Cursore grande:** spesso, colorato e lampeggiante, facile da ritrovare sulla pagina.
- **Barra dei tasti:** i tasti principali sono sempre visibili in fondo allo schermo (Maiusc + F2 la nasconde).
- **Richieste rapide a Claude:** Ctrl + 1 ortografia, Ctrl + 2 grammatica e punteggiatura, Ctrl + 3 ripetizioni e frasi lunghe, Ctrl + 4 idee per il titolo.
- **Rileggi il paragrafo:** Maiusc + F3 legge a voce il paragrafo in cui ti trovi.
- **Trova:** Ctrl + F per cercare una parola, Ctrl + G per la successiva; la riga viene letta a voce.
- **Importa file Word:** metti i file .docx, .odt, .rtf o .txt nella cartella Importa, poi F7 > Importa file Word.

Cambiato: la velocità di lettura ora è Ctrl + Maiusc + F3.

Se hai già Clara Writer, si aggiorna da solo al prossimo avvio.
