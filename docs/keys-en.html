Clara Writer: the keys

F1Where am I?  (Shift + F1: list of keys, read aloud)
F2Show or hide Claude
F3Read aloud from the cursor. F3 again or Esc to stop. Shift + F3: speed
F4Ask Claude  (Shift + F4: new conversation)
F5Dictation: F5 to start, F5 to stop
F6Open a text
F7New article, book or chapter
F8Undo Claude's changes
F9  /  F10Typeface  /  colours (Shift + F10: language)
F12Export to Word
Ctrl +  /  Ctrl −Bigger / smaller text
EscStop the voice, back to the text
